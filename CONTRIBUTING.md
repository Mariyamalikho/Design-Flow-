# Contributing to DesignFlow

First off, thanks for taking the time to contribute! 

## ?? Workflow
1. **Fork the repository** and clone it locally.
2. **Create a branch** for your feature or bugfix (`feature/my-feature` or `fix/issue-description`).
3. **Commit your changes** using the [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) format.
4. **Push your branch** to your fork.
5. **Open a Pull Request** against the `main` branch.

## ??? Development Setup
```bash
npm install
npm run dev
```

## ? Code Quality
Before submitting a PR, please ensure:
- You have run `npm run lint` and resolved any issues.
- Your code follows the existing Prettier formatting rules.
- Your commits are atomic (one logical change per commit).

Happy building! ??
